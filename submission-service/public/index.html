Your proposal

Describe a robotics problem worth turning into a benchmark task. A finished task package is not required.

Task and environment

Describe the objective, starting state, available inputs, constraints, and what the agent should deliver—as if assigning the work to a colleague.

Materials

Use links for supporting files at the proposal stage. Make sure the reviewers can access them.

Difficulty self-test (optional)

If you have tried an agent on the problem, share the result. You can propose an idea before running this test.

Drafts are visible only to you. Submitted proposals and feedback are visible to you and designated RLE-Bench reviewers.

Before you build

Start with the problem

  1. Choose a problem from real robotics engineering or research.
  2. Explain the starting point, expected result, and what makes it challenging.
  3. Define a reliable way to check success.
