# Introducing RLE-Bench

An interactive research article on evaluating coding agents as robot learning
engineers, with task demonstrations, leaderboards, and analysis.

- [Report (arXiv)](https://arxiv.org/pdf/2609.34210v2)
- [Original article](https://rle-bench.github.io/blog/)
- [Leaderboard](https://rle-bench.github.io/)
- [Benchmark code](https://github.com/RLE-Bench/RLE-Bench-dev)
- [Website source](https://github.com/RLE-Bench/RLE-Bench.github.io)

This Space is a static snapshot of the article and its published results.
Its HTML, JavaScript, charts, images, and videos are hosted together here.
The original website remains the canonical version.
